# Сайт yulia-math.ru — инструкция для агента

Одностраничный сайт репетитора по математике Юлии Ширяевой.
Хостинг: **GitHub Pages** из ветки `main`, папка `/` (root). Домен `yulia-math.ru` (файл `CNAME`).

## Главное правило
**После любой правки файлов сайта:**
1. `git add -A`
2. `git commit -m "<коротко по-русски, что изменено>"`
3. `git push origin main`

Через 1–2 минуты после push изменения появляются на https://yulia-math.ru.
Если push отклонён (на GitHub есть новые коммиты) — сначала `git pull --rebase origin main`, потом снова push.

## Структура
- `index.html` — вся страница (блоки: первый экран, тест, обо мне, галерея, система, цены, рефералка, отзывы, FAQ, контакты с формой)
- `css/style.css` — стили
- `js/main.js` — логика. В начале файла блок `CONFIG`: почта для заявок (`leadEmail`), контакты (`telegram`, `max`, `phone`, `whatsapp`, `email`), канал отзывов (`reviews`), номер Яндекс.Метрики (`metrika`). Там же массив `REVIEWS` (лента отзывов) и `QUESTIONS` (вопросы теста).
- `images/` — фото (jpg до ~1000 px по ширине, до ~150 КБ), `og.png` — превью ссылки 1200×630
- `CNAME`, `robots.txt`, `sitemap.xml` — не трогать без необходимости

## Правила
- Ссылок на Telegram-бота на сайте быть не должно. Все кнопки записи (`class="js-cta"`) ведут к разделу `#contacts` с формой.
- Точные цены не публиковать — только «от 1 200 ₽» и абонементы на 8 и 12 занятий.
- Сайт всегда светлый (тёмную тему не добавлять).
- Новые фото сжимать перед добавлением.
- Тексты — на русском, дружелюбно, без канцелярита.
- Перед push открыть `index.html` в браузере и убедиться, что страница не сломалась (нет ошибок в консоли).
